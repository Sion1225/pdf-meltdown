# PDF Meltdown

[English](README.md) | **日本語** | [한국어](README.ko.md)

**PDFを結合・分割・並べ替え。溶かして、そのまま使えるMarkdownにも。**

PySide6製のオフライン・デスクトップPDFツールです。**英語・スペイン語・日本語・韓国語のPDFをMarkdownに変換**
（スキャンのOCR、表、画像、数式のLaTeX化）し、ページの整理（結合・分割・並べ替え・抽出・回転）もできます。
処理はすべて手元のパソコンで行われます。
WindowsとmacOSで共通のコードです（現在はWindowsで開発・検証）。
表示言語: English · Español · 日本語 · 한국어（初回起動時はOSの言語に合わせます。設定で変更できます）。

## しくみ

すべての機能はひとつのモデルで動きます。PDFや画像を開くと、すべてのページがひとつのサムネイル一覧に
集まります。この一覧を操作して作業し、どの操作も元に戻せます。

| 機能 | 使い方 |
| --- | --- |
| **開く** | **開く**、またはエクスプローラーからPDF・画像（PNG/JPGなど）をウィンドウに**ドラッグ＆ドロップ**。画像はA4の1ページになります |
| **パスワード付きPDF** | 開くときにパスワードを入力すれば編集できます。そのまま保存するとパスワードなしで保存されます |
| **結合** | 複数のファイルを一覧に集めてから**保存** |
| **並べ替え** | サムネイルを**ドラッグ** |
| **回転** | **↺ / ↻**（選択ページを90°） |
| **空白ページ・複製** | **ページ ▾** → 空白ページを挿入 / ページを複製 |
| **元に戻す** | **元に戻す / やり直し**（最大100段階） |
| **抽出・分割** | **書き出し ▾** → 選択を抽出 / 分割（Nページごと、または選択ページの前で） |
| **詳細保存** | **書き出し ▾ → 詳細保存**: 圧縮（標準/強）・ページ番号・透かし・パスワード（AES-256） |
| **画像として書き出し** | **書き出し ▾** → PNG/JPG、72/150/300 DPI |
| **Markdown変換** | **書き出し ▾** → 一覧の現在の順序（全ページまたは選択ページ）で `.md` を作成 |

サムネイルを右クリックすると、回転・複製・削除などをすぐに使えます。

### Markdown変換

ページごとに適したエンジンを使い分けます。

- **デジタルページ**（テキスト層あり）→ PyMuPDF（pymupdf4llm）: 見出し・リスト・段落・表・画像、段組みの読み順を保持
- **スキャンページ**（画像のみ）→ xberg PaddleOCR: 英語・スペイン語・日本語・韓国語のOCR。複数の言語を選ぶとページごとに自動判別
  - スキャナーがあらかじめ埋め込んだ見えないOCR層（全面画像＋透明テキスト）は品質が当てにならないため、OCRし直します。
- **数式 → LaTeX**（任意、1ページあたり数秒追加）: xberg LaTeX-OCRで数式を見つけ、独立した行の数式は `$$…$$`、
  文中の数式は `$…$` として入れます。スキャン・デジタルどちらのページにも対応（文中の短いインライン数式は検出されないことがあります）。
- オプション: OCR 自動/使用しない/全ページ、OCRモデル 高速/高精度、画像 フォルダに保存/埋め込む/含めない、
  スキャンページの元画像を添付、ページ区切り線
- 画像は `文書名_assets/page003_01.png` の形で保存され、相対パスでリンクされます。

既知の制限: 罫線のない表は通常のテキストになることがあり、結合セルは内容が複製されます。
スキャンページ内の写真は個別に切り出せないため、必要なら「スキャンページの元画像も添付」をオンにしてください。
Markdownは位置を表現できないため、見た目の配置ではなく構造（見出し・段落・リスト・表・順序）を保持します。

### パフォーマンス

- **すぐに開けます**: ページ数だけを読んで一覧をグレーのプレースホルダーで埋め、実際のサムネイルは
  バックグラウンドのスレッドプールで**並列に描画**します（大きなPDFでもUIが固まりません）。
- 読み込み中はステータスバーに**進捗バー**が表示され、描画が終わったページから順にサムネイルが表示されます。
- サムネイルは220pxで一度だけ描画し、表示サイズだけを変えるので、サイズ変更は一瞬です。
- 保存・抽出・分割・変換はバックグラウンドで実行され、進捗ダイアログからキャンセルできます。

## インストール

```powershell
git clone https://github.com/Sion1225/pdf-meltdown.git
cd pdf-meltdown
python -m pip install -r requirements.txt
# スキャンページのOCRと数式認識も使う場合（任意）
python -m pip install -r requirements-markdown.txt
```

## 実行

```powershell
python run.py
```

## ショートカット

| キー | 操作 |
| --- | --- |
| Ctrl+O | 開く / 追加 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+L / Ctrl+R | 左に回転 / 右に回転 |
| Ctrl+B | 空白ページを挿入 |
| Ctrl+D | ページを複製 |
| Delete | 選択を削除 |
| Ctrl+S | すべて保存（結合） |
| Ctrl+Shift+E | 詳細保存 |
| Ctrl+E | 選択を抽出 |
| Ctrl+Shift+S | 分割 |
| Ctrl+M | Markdown変換 |

macOSではCtrlの代わりに⌘キーを使います。

## 構成

```
pdf-meltdown/
  run.py              # 起動エントリーポイント
  app/
    core.py           # ページモデル（PageRef: 回転・空白ページ）と保存/分割（pypdf）、GUI非依存
    postprocess.py    # 詳細保存: 圧縮・ページ番号・透かし・パスワード（PyMuPDF）
    images.py         # 画像 → PDFページ、ページ → 画像ファイル
    render.py         # サムネイル描画、パスワード付きPDFを開く（PyMuPDF）
    jobs.py           # バックグラウンドの書き出し処理（進捗/キャンセル）
    convert/          # PDF → Markdown（pipeline: ページごとのエンジン選択、native: PyMuPDF、ocr: xberg、
                      #                 formulas: 数式 → LaTeX）
    dialogs.py        # 詳細保存 / 画像書き出しダイアログ
    i18n.py           # 表示文言（en, es, ja, ko）
    main_window.py    # GUI（PySide6）
```

## 配布（任意）

PyInstallerで単体の実行ファイルを作れます。

```powershell
python -m pip install pyinstaller
pyinstaller --noconfirm --windowed --name "PDF Meltdown" run.py
```

macOSでも同じ方法で `.app` バンドルを作れます（そのOS上でビルドする必要があります）。
